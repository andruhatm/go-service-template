### 4. Формулы и математика ✅

Все метрики с полными формулами:

```
MAE = (1/n) × Σ|yᵢ - ŷᵢ|

RMSE = √[(1/n) × Σ(yᵢ - ŷᵢ)²]

WAPE = [Σ|yᵢ - ŷᵢ|] / [Σ|yᵢ|] × 100%

MAPE = (100%/n) × Σ|((yᵢ - ŷᵢ)/yᵢ)|

R² = 1 - (SS_res / SS_tot)
```

## 🎓 Ответы на возможные вопросы комиссии

### Вопрос 1: "Почему использовали WAPE, а не MAPE?"

**Ответ (из раздела 2.1):**
"MAPE имеет проблему асимметричности и чувствительности к малым значениям. Например, при y=5 и ошибке в 5 единиц MAPE будет 100%, хотя абсолютная ошибка невелика. WAPE агрегирует ошибки перед нормализацией, что устраняет эти проблемы. На примере с выбросом показано, что MAPE дал 27,3%, а WAPE - 4,6%, что адекватнее отражает качество."

### Вопрос 2: "Как вы считали метрики?"

**Ответ (из раздела 3):**
"Покажу на примере линейного тренда. Для 168 точек рассчитывали:
1. Сумму абсолютных ошибок: 444,66
2. WAPE = 444,66 / 365044,32 × 100% = 0,12%
3. MAE = 444,66 / 168 = 2,65
4. RMSE через среднеквадратичную ошибку
Все расчеты верифицированы через RMSE/MAE = 1,14, что соответствует нормальному распределению."

### Вопрос 3: "Достаточно ли 180 дней данных?"

**Ответ (из раздела 1.1):**
"180 дней данных обеспечивают 150 полных суточных циклов и 21,4 недельных цикла для обучения. Это статистически достаточно для надежной оценки сезонных компонентов. Тестовая выборка 168 точек (7 дней) покрывает полную неделю для валидации."

### Вопрос 4: "Почему baseline модель, а не нейросети?"

**Ответ (из раздела 5):**
"Baseline модель показала отличные результаты на 78% метрик (WAPE < 5%) при минимальных вычислительных требованиях (0,002 сек на прогноз). Результаты в 1,5-2,1 раза лучше сложных методов из литературы. Для промышленного применения важна не только точность, но и скорость и воспроизводимость."
