## Методика поиска на платформе Роспатент

### Шаг 1: Простой поиск
1. Откройте https://searchplatform.rospatent.gov.ru/patents
2. В поле "Что вы ищете?" введите запрос:
   - "мониторинг прогнозирование базовая станция"
   - "прогнозирование временные ряды телекоммуникация"
   - "автоматизированная система мониторинг сеть связи"

### Шаг 2: Расширенный поиск
1. Перейдите на вкладку "Расширенный поиск"
2. Заполните поля:
   - **Название:** мониторинг, прогнозирование, базовая станция
   - **Реферат:** временной ряд, аддитивная модель, сезонность
   - **МПК:** H04W 24/00, H04W 24/02, H04W 24/08, G06F 17/18

### Шаг 3: Фильтры
- **Дата публикации от:** 01.01.2015 (последние 10 лет)
- **Вид документа:** Патенты на изобретение, Полезные модели
- **Поисковые массивы:** Российские патенты (RU)

### Шаг 4: Поиск по классификаторам
Используйте раздел "Классификаторы" для поиска по МПК:
- **H04W 24/00-08** — Мониторинг беспроводных сетей
- **H04L 41/14-16** — Мониторинг компьютерных сетей
- **G06F 17/18** — Статистическая обработка данных

## Инструкция по цитированию патентов

### Для российских патентов (ГОСТ Р 7.0.5-2008)

**Формат:**
Номер патента. Название / Правообладатель. — Дата публикации.

**Пример:**
RU2722924C1. Способ моделирования варианта построения распределенной сети связи вышестоящей системы управления. — Опубл. 04.06.2020.

### Для зарубежных патентов

**Формат:**
Patent Number. Title / Assignee. — Issue/Publication Date.

**Пример:**
US11063842B2. Forecasting Network KPIs / Cisco Technology, Inc. — Issued: July 13, 2021.
