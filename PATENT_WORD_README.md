## 🚀 Быстрая инструкция

### Вставка таблицы в Word

**Способ 1: Автоматическое преобразование (рекомендуется)**

1. Откройте файл `PATENT_TABLE_SIMPLE.txt`
2. Найдите раздел "УПРОЩЕННАЯ ВЕРСИЯ ДЛЯ КОПИРОВАНИЯ"
3. Скопируйте текст начиная с "Признак..." до конца таблицы
4. Вставьте в Word (Ctrl+V)
5. Выделите вставленный текст
6. **Вставка → Таблица → Преобразовать в таблицу**
7. Выберите "Разделитель: знак табуляции"
8. Нажмите "ОК"
9. Отформатируйте таблицу:
   - Границы: Конструктор → Стили границ
   - Заливка: Конструктор → Заливка
   - Шрифт: Выделить первую строку → Полужирный

**Способ 2: Ручное создание**

1. Откройте `PATENT_COMPARISON_FOR_WORD.md`
2. Найдите Таблицу 1
3. Создайте таблицу в Word: Вставка → Таблица → 5 столбцов × 17 строк
4. Скопируйте данные построчно
