# Изменения: Добавлена страница просмотра прогноза с графиком

## Краткое описание

Добавлена возможность просматривать результаты прогноза на отдельной странице с интерактивным линейным графиком, показывающим:
- Текущие/исторические значения метрики
- Спрогнозированные точки
- Пороговое значение (если настроено)

## Как работает

1. **Пользователь нажимает кнопку "Просмотр"** в списке прогнозов
2. **Переход на `/anomaly/{forecast-id}`**
3. **ForecastDetailComponent загружает метаданные прогноза** через ForecastService
4. **Если статус = "completed":**
   - Загружаются исторические данные (type="actual")
   - Загружаются прогнозные данные (type="forecast", forecast_id=uuid)
5. **Данные преобразуются** в формат для ngx-charts
6. **Отображается интерактивный график** с двумя линиями:
   - Синяя: исторические данные
   - Оранжевая: прогнозные данные

## API изменения

### POST /api/metrics/query

**Было:**
```json
{
  "metricName": "test1",
  "objectName": "enb27738",
  "startTime": 1672531200,
  "endTime": 1704067200,
  "step": 3600
}
```

**Стало:**
```json
{
  "metricName": "test1",
  "objectName": "enb27738",
  "startTime": 1672531200,
  "endTime": 1704067200,
  "step": 3600,
  "type": "forecast",          // НОВОЕ (опционально)
  "forecastId": "uuid-string"  // НОВОЕ (опционально)
}
```

### PromQL запросы

**Без фильтров:**
```
test1{name="enb27738"}
```

**С type:**
```
test1{name="enb27738", type="actual"}
```

**С type и forecast_id:**
```
test1{name="enb27738", type="forecast", forecast_id="uuid"}
```

```bash

```

## Возможные проблемы и решения

### 1. График не отображается
**Причина:** Нет данных в VictoriaMetrics  
**Решение:** Проверить, что forecast-service записал данные с правильными метками

### 2. Ошибка "Forecast not found"
**Причина:** Неверный ID или права доступа  
**Решение:** Проверить, что пользователь имеет доступ к прогнозу

### 3. Пустой график для completed прогноза
**Причина:** Данные не найдены по фильтрам  
**Решение:** Проверить метки в VictoriaMetrics (name, type, forecast_id)

### 4. Ошибка компиляции Angular
**Причина:** Отсутствует NgxChartsModule  
**Решение:** `npm install` для установки зависимостей
