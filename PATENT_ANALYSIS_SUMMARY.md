## 2. Ближайшие патентные аналоги

### 2.1. Аналог 1: US11063842B2 (Cisco Systems, 2021)

**Название:** "Forecasting Network KPIs"

**Сущность:** Система прогнозирования KPI сетевого оборудования с использованием ансамбля моделей машинного обучения (градиентный бустинг, нейронные сети) на гетерогенных данных.

**Отличия от разрабатываемой системы:**
- Использует сложные ML-модели вместо аддитивной декомпозиции
- Вычислительная сложность O(n log n) против O(n)
- Не выделяет явно трендовую и сезонную компоненты
- Требует значительно больший объем данных для обучения (6+ месяцев)
- Низкая интерпретируемость результатов ("черный ящик")

**МПК:** H04L 41/14, G06N 20/00

### 2.2. Аналог 2: US20250142379A1 (AT&T, 2025)

**Название:** "Identifying a Performance Issue Associated with a 5G Wireless Telecommunication Network"

**Сущность:** Автоматизированная система обнаружения проблем производительности в 5G сетях с классификацией 4 типов аномалий (внезапная деградация, изменение тренда, постепенное ухудшение, приближение к пределу емкости).

**Отличия от разрабатываемой системы:**
- Фокус на обнаружении аномалий, а не на долгосрочном прогнозировании
- Не предоставляет количественные прогнозы значений метрик
- Требует размеченных данных о проблемах для обучения
- Вычислительная сложность O(n²) против O(n)
- Краткосрочный горизонт (обнаружение событий) против 7-дневного прогноза

**МПК:** H04W 24/08

### 2.3. Аналог 3: US9900790B1 (T-Mobile USA, 2018)

**Название:** "Prediction of Performance Indicators in Cellular Networks"

**Сущность:** Прогнозирование показателей производительности сотовых сетей на основе простых статистических моделей (скользящее среднее) по историческим данным.

**Отличия от разрабатываемой системы:**
- Не учитывает сезонную компоненту
- Ограниченная точность при сложных паттернах
- Отсутствие механизма rolling window validation
- Малая обучающая выборка (30 дней против 150 дней)
- Статическая модель без автоматической адаптации

**МПК:** H04W 24/02

### 2.4. Аналог 4: RU2722924C1 (2020)

**Название:** "Способ моделирования варианта построения распределенной сети связи вышестоящей системы управления"

**Сущность:** Способ моделирования распределенных сетей связи с использованием принципа максимума энтропии для оценки показателей качества функционирования.

**Отличия от разрабатываемой системы:**
- Фокус на моделировании структуры сети, а не на прогнозировании временных рядов
- Отсутствие компоненты мониторинга в реальном времени
- Не предназначен для оперативного прогнозирования
- Применяется для проектирования, а не эксплуатации сети

**МПК:** H04L 41/14

### 2.5. Аналог 5: RU40559U1 (2004)

**Название:** "Система мониторинга телекоммуникационных сетей SPIDER"

**Сущность:** Система мониторинга общеканальных систем сигнализации (ОКС) с обнаружением отказов и формированием отчетов.

**Отличия от разрабатываемой системы:**
- Полное отсутствие компоненты прогнозирования
- Реактивный подход (обнаружение проблем постфактум)
- Устаревшая архитектура (2004 год)
- Ограниченная функциональность

**МПК:** H04L 41/14

## 4. Отличительные признаки разрабатываемой системы

На основании патентного анализа выявлены следующие **отличительные признаки**, не обнаруженные в аналогах:

### 4.1. Явная аддитивная декомпозиция временных рядов

Применение модели вида $y(t) = T(t) + S(t) + E(t)$ с раздельным моделированием:
- Трендовой компоненты $T(t)$ методом линейной регрессии
- Сезонной компоненты $S(t)$ гармоническим анализом
- Остаточной компоненты $E(t)$ для обнаружения аномалий

**Преимущества:** Высокая интерпретируемость, низкая вычислительная сложность, возможность анализа отдельных компонент.

**Отличие от аналогов:** Все найденные ML-аналоги используют "черный ящик" без явной декомпозиции.

### 4.2. Гармонический анализ суточной сезонности

Моделирование суточных циклов нагрузки формулой:

$$S(h) = A \cdot \sin\left(\frac{2\pi(h - \phi)}{24}\right)$$

где $A$ — амплитуда, $\phi$ — фазовый сдвиг, $h$ — час суток.

**Преимущества:** Параметры имеют физический смысл, малое количество параметров (2-3 против десятков в ML).

**Отличие от аналогов:** Аналоги учитывают сезонность неявно через признаки или скрытые слои нейросетей.

### 4.3. Rolling window validation с ежечасным обновлением

Методология непрерывной адаптации модели с фиксированным окном обучения 3600 точек (150 дней) и ежечасным автоматическим переобучением.

**Преимущества:** Модель всегда актуальна, быстрое обнаружение изменений трендов, не требуется полное переобучение.

**Отличие от аналогов:** Аналоги используют периодическое полное переобучение (раз в неделю/месяц) или статические модели.

### 4.4. Комплексная валидация на длинном горизонте

Валидация на синтетическом наборе данных:
- Период: 180 дней (4321 точка)
- Типы паттернов: 9 (тренды, сезонность, аномалии, шум)
- Метрика качества: WAPE = 3,90%

**Преимущества:** Доказана устойчивость к разным типам поведения метрик, репродуцируемость результатов.

**Отличие от аналогов:** В патентах не указаны детали валидации, типичные тесты — на 30-60 днях.

### 4.5. Открытая модульная архитектура

Система построена на открытых технологиях:
- Prometheus/VictoriaMetrics (сбор метрик)
- Python + FastAPI (сервис прогнозирования)
- Go (backend)
- Angular (frontend)
- PostgreSQL (хранение)
- REST API (OpenAPI 3.0)

**Преимущества:** Независимость от vendor lock-in, низкая стоимость внедрения, возможность интеграции с любыми системами.

**Отличие от аналогов:** Все коммерческие аналоги — проприетарные решения.

### 4.6. Специализация для телекоммуникационных метрик

Оптимизация модели для характеристик метрик базовых станций:
- Суточная сезонность (пиковые нагрузки в рабочее время)
- Линейные тренды деградации оборудования
- Редкие аномалии (выбросы, сбои)

**Преимущества:** Более высокая точность по сравнению с универсальными решениями в телеком-домене.

**Отличие от аналогов:** ML-аналоги позиционируются как универсальные для любых сетевых KPI.

## 6. Формула изобретения (проект для научной работы)

**СПОСОБ ПРОГНОЗИРОВАНИЯ ВРЕМЕННЫХ РЯДОВ МЕТРИК ФУНКЦИОНИРОВАНИЯ БАЗОВЫХ СТАНЦИЙ СОТОВОЙ СВЯЗИ**

Способ прогнозирования временных рядов метрик функционирования базовых станций сотовой связи, включающий сбор исторических данных о значениях метрик, обработку данных и формирование прогноза, **отличающийся тем, что**:

- выполняют декомпозицию временного ряда на трендовую компоненту T(t), сезонную компоненту S(t) и остаточную компоненту E(t) согласно аддитивной модели: 
  $$y(t) = T(t) + S(t) + E(t)$$

- определяют трендовую компоненту T(t) методом линейной регрессии на обучающей выборке размером не менее 3600 почасовых измерений;

- определяют сезонную компоненту S(t) путем гармонического анализа с суточной периодичностью в форме: 
  $$S(h) = A \cdot \sin\left(\frac{2\pi(h-\phi)}{24}\right)$$
  где h — час суток, A — амплитуда, φ — фазовый сдвиг;

- формируют прогноз на горизонт 168 часов путем суммирования экстраполированных значений трендовой и сезонной компонент;

- осуществляют ежечасное обновление модели методом скользящего окна (rolling window) с фиксированным размером обучающей выборки.
