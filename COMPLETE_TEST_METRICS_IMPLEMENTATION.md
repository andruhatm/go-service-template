## 📈 Особенности реализации

### 1. Разнообразие паттернов
Каждая метрика демонстрирует уникальный временной паттерн:
- **Тренды**: линейный рост/снижение, экспоненциальный рост
- **Сезонность**: суточная, недельная
- **Стабильность**: константа, случайное блуждание
- **Аномалии**: редкие выбросы (5% вероятность)
- **Комбинации**: тренд + сезонность

### 2. Формат Prometheus
Данные записаны в стандартном формате Prometheus exposition:
```
metric_name{name="object_name",type="actual"} value timestamp
```

Пример:
```
test_metric_uptrend{name="test_node_01",type="actual"} 102.34 1765665756030
```

### 3. Метки для фильтрации
Каждая точка данных имеет метки:
- `name` - имя объекта мониторинга
- `type="actual"` - тип данных (исторические)

Это позволяет отличать исторические данные от прогнозов:
- Исторические: `type="actual"`
- Прогнозные: `type="forecast", forecast_id="uuid"`

### 4. Воспроизводимость
Данные сохранены в файлы и могут быть:
- Загружены в VictoriaMetrics повторно
- Проанализированы в Excel/Python
- Использованы для автоматизированных тестов

## 🔍 Технические детали

### Генератор данных

**Язык:** Python 3
**Зависимости:** Только стандартная библиотека (math, random, datetime)

**Основные функции:**
```python
generate_timestamps()  # Создает временные метки
pattern_*()           # Функции генерации паттернов
generate_prometheus_format()  # Экспорт в Prometheus
generate_csv_format()        # Экспорт в CSV
```

**Паттерны реализованы математически:**
- Линейные: `y = base + slope * x + noise`
- Синусоидальные: `y = base + amplitude * sin(2πx/period) + noise`
- Экспоненциальные: `y = base * exp(rate * x) + noise`
- Ступенчатые: `y = base + step * floor(x / interval) + noise`

### Формат timestamp
Все timestamp в миллисекундах (Unix timestamp × 1000)

### Шум
Каждая точка имеет случайный шум для реалистичности:
- Малый шум: ±2 (для константы)
- Средний шум: ±5 (для большинства паттернов)
- Большой шум: ±8 (для random walk)
