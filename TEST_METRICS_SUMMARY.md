## 🎯 Рекомендации по тестированию

### Начните с простых паттернов

#### 1. Константное значение (самый простой)
```
Метрика: test_metric_constant
Объект: test_node_06
Параметры:
  - Периоды: 168 (7 дней)
  - Частота: H
  - Режим: additive
  - Changepoint: 0.05
```
**Ожидаемый результат:** Прогноз близок к ~100 с малыми отклонениями

#### 2. Линейный тренд (легкий)
```
Метрика: test_metric_uptrend
Объект: test_node_01
Параметры:
  - Периоды: 168 (7 дней)
  - Частота: H
  - Режим: additive
  - Changepoint: 0.05
```
**Ожидаемый результат:** Прогноз продолжает линейный рост

#### 3. Суточная сезонность (средний)
```
Метрика: test_metric_daily_season
Объект: test_node_03
Параметры:
  - Периоды: 168 (7 дней)
  - Частота: H
  - Режим: multiplicative
  - Changepoint: 0.1
```
**Ожидаемый результат:** Прогноз повторяет суточный цикл

#### 4. Комбинированный паттерн (сложный)
```
Метрика: test_metric_trend_season
Объект: test_node_08
Параметры:
  - Периоды: 168-336 (7-14 дней)
  - Частота: H
  - Режим: multiplicative
  - Changepoint: 0.05
```
**Ожидаемый результат:** Прогноз учитывает и тренд, и сезонность

## 🔍 Проверка результатов

### Проверка через API

```bash
# 1. Проверить список метрик
curl -s 'http://localhost:8428/api/v1/label/__name__/values' | jq . | grep test_metric

# 2. Получить данные одной метрики
curl -s 'http://localhost:8428/api/v1/query?query=test_metric_uptrend{name="test_node_01"}' | jq .

# 3. Получить временной ряд за последнюю неделю
START=$(date -u -d '7 days ago' +%s)
END=$(date -u +%s)
curl -s "http://localhost:8428/api/v1/query_range?query=test_metric_uptrend{name=\"test_node_01\"}&start=$START&end=$END&step=3600" | jq .

# 4. Проверить количество точек
curl -s 'http://localhost:8428/api/v1/query?query=count(test_metric_uptrend{name="test_node_01"})' | jq .
```

### Проверка прогнозов

```bash
# Список прогнозов (требуется токен)
curl -X GET 'http://localhost:8080/api/forecasts' \
  -H "Authorization: Bearer $TOKEN"

# Конкретный прогноз
curl -X GET 'http://localhost:8080/api/forecasts/{forecast-id}' \
  -H "Authorization: Bearer $TOKEN"
```

## 🎓 Образовательные примеры

### Пример 1: Влияние seasonality_mode

**Тест с additive:**
```json
{
  "metric": "test_metric_daily_season",
  "seasonality_mode": "additive",
  "forecast_periods": 168
}
```

**Тест с multiplicative:**
```json
{
  "metric": "test_metric_daily_season",
  "seasonality_mode": "multiplicative",
  "forecast_periods": 168
}
```

**Сравните графики:** multiplicative обычно лучше для пропорциональных изменений

### Пример 2: Влияние changepoint_prior_scale

**Низкое значение (0.05):**
- Более консервативный прогноз
- Меньше адаптации к изменениям
- Подходит для стабильных метрик

**Высокое значение (0.5):**
- Более гибкий прогноз
- Лучше адаптируется к изменениям
- Подходит для волатильных метрик

**Протестируйте на:** `test_metric_step_changes`

### Пример 3: Длина исторических данных

**30 дней:** Стандартный прогноз
**60 дней:** Более точный для сезонных паттернов
**7 дней:** Быстрый прогноз (может быть менее точным)
