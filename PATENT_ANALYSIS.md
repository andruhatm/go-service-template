## 1. Описание разрабатываемой системы

**Автоматизированная система мониторинга и прогнозирования показателей функционирования станций сотовой связи** представляет собой программно-аппаратный комплекс, предназначенный для:

- **Непрерывного мониторинга** ключевых показателей производительности (KPI) базовых станций сотовой связи в режиме реального времени
- **Прогнозирования временных рядов** метрик сетевого оборудования на основе аддитивной модели декомпозиции
- **Автоматического обнаружения аномалий** и отклонений от ожидаемого поведения системы
- **Формирования уведомлений** о критических событиях и прогнозируемых проблемах

### 1.1. Ключевые особенности системы

**Математическая модель прогнозирования:**
Система использует аддитивную модель декомпозиции временных рядов вида:

$$y(t) = T(t) + S(t) + E(t)$$

где:
- $T(t)$ — трендовая компонента, аппроксимируемая линейной регрессией
- $S(t)$ — сезонная компонента, моделируемая гармоническим анализом с суточной периодичностью
- $E(t)$ — остаточная компонента (шум)

**Технические характеристики:**
- Горизонт прогнозирования: 168 часов (7 дней)
- Частота обновления прогнозов: каждый час
- Обучающая выборка: 3600 точек (150 дней)
- Точность прогнозирования: WAPE = 3,90% (по результатам валидации на 180-дневном наборе данных)
- Rolling window validation для непрерывного обучения модели

**Архитектурные компоненты:**
- Модуль сбора метрик из Prometheus/VictoriaMetrics
- Сервис прогнозирования на базе Python (FastAPI)
- Backend на Go для управления данными и уведомлениями
- Frontend на Angular для визуализации и управления
- PostgreSQL для хранения результатов прогнозов и настроек

## 4. Анализ ближайших аналогов

Для детального сравнения выбраны **5 ближайших аналогов**, максимально соответствующих функциональности разрабатываемой системы.

### 4.1. Аналог 1: US11063842B2 (Cisco Systems, 2021)

**Название:** "Forecasting Network KPIs"

**Сущность изобретения:**
Патент описывает систему прогнозирования ключевых показателей эффективности (KPI) сетевого оборудования с использованием моделей машинного обучения. Система обучает модели на гетерогенных данных, включая:
- Синхронные временные ряды метрик
- Асинхронные события в сети
- Граф взаимосвязей сетевых объектов

**Технические особенности:**
- Кластеризация сетевых объектов по типам
- Выбор релевантных признаков для каждого кластера
- Использование множества моделей ML (градиентный бустинг, нейронные сети)
- Прогнозирование на горизонт от нескольких минут до нескольких дней

**Недостатки:**
- Высокая вычислительная сложность обучения множества моделей
- Требуется значительный объем данных для обучения
- Необходимость экспертной настройки параметров для каждого кластера
- Не учитывается сезонная компонента явным образом

### 4.2. Аналог 2: US20250142379A1 (AT&T, 2025)

**Название:** "Identifying a Performance Issue Associated with a 5G Wireless Telecommunication Network"

**Сущность изобретения:**
Автоматизированная система идентификации проблем производительности в сетях 5G с использованием множественных моделей машинного обучения. Система выполняет:
- Сбор KPI из сетевых ячеек
- Предобработку данных (снижение шума, нормализация)
- Обнаружение четырех типов проблем:
  1. Внезапная деградация производительности
  2. События, вызывающие изменение тренда
  3. Постепенное ухудшение производительности
  4. Приближение к пределу емкости

**Технические особенности:**
- Ансамбль моделей ML для разных типов аномалий
- Предобработка данных с уменьшением шума
- Нормализация значений KPI
- Автоматическая классификация типа проблемы

**Недостатки:**
- Фокус на обнаружении аномалий, а не на долгосрочном прогнозировании
- Не предоставляет количественные прогнозы значений метрик
- Требует обучения на размеченных данных о проблемах
- Высокая вычислительная сложность ансамбля моделей

### 4.3. Аналог 3: US9900790B1 (T-Mobile USA, 2018)

**Название:** "Prediction of Performance Indicators in Cellular Networks"

**Сущность изобретения:**
Система прогнозирования показателей производительности сотовых сетей с использованием предиктивных моделей на основе исторических и текущих данных.

**Технические особенности:**
- Сбор метрик производительности базовых станций
- Построение моделей на основе исторических паттернов
- Прогнозирование будущих значений KPI
- Интеграция с системами управления сетью

**Недостатки:**
- Простые статистические модели без явной декомпозиции
- Ограниченная точность при сложных паттернах
- Не учитывается множественная сезонность (суточная + недельная)
- Отсутствие механизма rolling window validation

### 4.4. Аналог 4: RU2722924C1 (2020)

**Название:** "Способ моделирования варианта построения распределенной сети связи вышестоящей системы управления"

**Сущность изобретения:**
Российский патент на способ моделирования распределенных сетей связи с использованием принципа максимума энтропии для оценки показателей качества.

**Технические особенности:**
- Моделирование топологии сети
- Оценка показателей качества функционирования
- Использование энтропийного подхода для определения весов частных показателей
- Повышение достоверности оценки процессов в сети

**Недостатки:**
- Фокус на моделировании структуры сети, а не на прогнозировании временных рядов
- Отсутствие компоненты мониторинга в реальном времени
- Не предназначен для оперативного прогнозирования
- Сложность практического применения

### 4.5. Аналог 5: RU40559U1 (2004)

**Название:** "Система мониторинга телекоммуникационных сетей SPIDER"

**Сущность изобретения:**
Российская полезная модель, описывающая систему мониторинга телекоммуникационных сетей, в частности для контроля общеканальных систем сигнализации (ОКС).

**Технические особенности:**
- Непрерывный мониторинг состояния телекоммуникационной сети
- Сбор данных о функционировании системы сигнализации
- Обнаружение отказов и сбоев
- Формирование отчетов о состоянии сети

**Недостатки:**
- Отсутствие компоненты прогнозирования
- Реактивный подход (обнаружение проблем постфактум)
- Ограниченная функциональность по сравнению с современными требованиями
- Устаревшая архитектура (2004 год)

## 6. Выводы о новизне

### 6.1. Отличительные признаки разрабатываемой системы

На основании проведенного патентного анализа выявлены следующие **отличительные признаки** разрабатываемой системы:

#### 1. Явная аддитивная декомпозиция временных рядов

**Новизна:** Ни один из найденных патентов не использует явную аддитивную модель декомпозиции вида $y(t) = T(t) + S(t) + E(t)$ с раздельным моделированием трендовой и сезонной компонент.

**Преимущества:**
- Высокая интерпретируемость результатов (эксперты понимают вклад каждой компоненты)
- Возможность анализа отдельных компонент (например, долгосрочного тренда деградации оборудования)
- Низкая вычислительная сложность O(n)
- Не требуется большой объем размеченных данных для обучения

#### 2. Гармонический анализ для моделирования суточной сезонности

**Новизна:** Использование гармонической функции $S(h) = A \sin\left(\frac{2\pi(h - \phi)}{24}\right)$ для моделирования суточных циклов нагрузки базовых станций.

**Преимущества:**
- Точное воспроизведение суточных паттернов трафика
- Параметры $A$ (амплитуда) и $\phi$ (фаза) имеют физический смысл
- Устойчивость к выбросам при оценке параметров
- Малое количество параметров (2-3 параметра против десятков в ML моделях)

#### 3. Rolling window validation с ежечасным обновлением

**Новизна:** Методология непрерывного обновления модели каждый час с использованием скользящего окна 150 дней.

**Преимущества:**
- Модель адаптируется к изменениям в поведении сети
- Не требуется полное переобучение при поступлении новых данных
- Гарантированная актуальность прогнозов
- Автоматическое обнаружение изменения трендов

#### 4. Валидация на длинном горизонте (180 дней, 4321 точка)

**Новизна:** Комплексная валидация на синтетических данных с разнообразными паттернами (9 типов), покрывающими полугодовой период.

**Преимущества:**
- Доказана устойчивость к различным типам паттернов (тренды, сезонность, аномалии, шум)
- Подтверждена высокая точность (WAPE = 3,90%)
- Репродуцируемость результатов
- Научная обоснованность подхода

#### 5. Открытая модульная архитектура

**Новизна:** Система построена на открытых технологиях (Prometheus, PostgreSQL, FastAPI, Angular) с публичным REST API.

**Преимущества:**
- Интеграция с любыми системами мониторинга
- Возможность расширения функциональности
- Независимость от проприетарных решений
- Снижение стоимости внедрения

#### 6. Специализация для телекоммуникационных метрик

**Новизна:** Оптимизация модели для специфических характеристик метрик базовых станций (суточная сезонность, линейные тренды деградации, редкие аномалии).

**Преимущества:**
- Более высокая точность по сравнению с универсальными решениями
- Учет доменной специфики (например, пиковые нагрузки в рабочие часы)
- Возможность прогнозирования деградации оборудования
- Адаптация к сезонным изменениям трафика

## Приложение Б. Формула изобретения (проект)

### СПОСОБ ПРОГНОЗИРОВАНИЯ ВРЕМЕННЫХ РЯДОВ МЕТРИК СЕТЕВОГО ОБОРУДОВАНИЯ

**Формула изобретения**

1. Способ прогнозирования временных рядов метрик функционирования базовых станций сотовой связи, включающий сбор исторических данных о значениях метрик, обработку данных и формирование прогноза, **отличающийся тем, что**:
   
   - выполняют декомпозицию временного ряда на трендовую компоненту T(t), сезонную компоненту S(t) и остаточную компоненту E(t) согласно аддитивной модели: y(t) = T(t) + S(t) + E(t);
   
   - определяют трендовую компоненту T(t) методом линейной регрессии на обучающей выборке размером не менее 3600 почасовых измерений;
   
   - определяют сезонную компоненту S(t) путем гармонического анализа с суточной периодичностью в форме: S(h) = A·sin((2π(h-φ)/24)), где h — час суток, A — амплитуда, φ — фазовый сдвиг;
   
   - формируют прогноз на горизонт 168 часов путем суммирования экстраполированных значений трендовой и сезонной компонент;
   
   - осуществляют ежечасное обновление модели методом скользящего окна (rolling window) с фиксированным размером обучающей выборки.

2. Способ по п. 1, **отличающийся тем, что** размер обучающей выборки составляет 3600 почасовых измерений, что соответствует периоду наблюдений 150 дней.

3. Способ по п. 1, **отличающийся тем, что** при формировании прогноза дополнительно выполняют обнаружение аномалий путем сравнения остаточной компоненты E(t) с пороговым значением, определяемым как 3-кратное стандартное отклонение.

4. Способ по п. 1, **отличающийся тем, что** оценку точности прогнозирования выполняют на тестовой выборке размером 168 точек с использованием метрики WAPE (Weighted Absolute Percentage Error).
