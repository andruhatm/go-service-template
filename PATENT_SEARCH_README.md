## О проекте

Данная документация содержит результаты комплексного патентного анализа для системы **"Автоматизированная система мониторинга и прогнозирования показателей функционирования станций сотовой связи"**.

**Цель анализа:**
- Провести патентный поиск на платформе Роспатент и в международных базах
- Выявить ближайшие аналоги
- Определить отличительные признаки разрабатываемой системы
- Оценить патентоспособность решения
- Подготовить материалы для научной работы

**Дата проведения:** 2 февраля 2026 г.

### Патентоспособность

#### ✅ Новизна (ст. 1350 ГК РФ)
Совокупность отличительных признаков не обнаружена в известных решениях

#### ✅ Изобретательский уровень (ст. 1351 ГК РФ)
- Точность WAPE = 3,90% **в 2-5 раз лучше** типичных значений (10-20%)
- Вычислительная сложность O(n) **в 10-100 раз ниже** ML-аналогов
- Сочетание простоты и точности **неочевидно**

#### ✅ Промышленная применимость (ст. 1352 ГК РФ)
- Система реализована и протестирована
- Применима для операторов связи (МегаФон, МТС, Билайн, Теле2)
- Может быть воспроизведена

| Аспект | Разрабатываемая система | Аналоги (ML) |
|--------|-------------------------|--------------|
| **Точность** | WAPE 3,90% (валидировано) | Не указана / 10-20% |
| **Интерпретируемость** | ⭐⭐⭐⭐⭐ Высокая (явные компоненты) | ⭐⭐ Низкая (black box) |
| **Вычислительная сложность** | O(n) — линейная | O(n log n) - O(n²) |
| **Время обучения** | <1 минута (CPU) | 1-8 часов (GPU) |
| **Требования к данным** | 150 дней | 6+ месяцев |
| **Адаптация** | Ежечасно (rolling window) | Периодическое переобучение |
| **Стоимость внедрения** | Низкая (open source) | Высокая (proprietary) |
