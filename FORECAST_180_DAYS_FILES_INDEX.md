## 🔄 Процесс воспроизведения

### Шаг 1: Генерация данных (3 минуты)
```bash
export TEST_METRICS_DAYS=180
python3 generate_test_metrics.py
```
**Результат:** `test_metrics_prometheus.txt`, `test_metrics_data.csv`, `test_metrics_summary.txt`

### Шаг 2: Загрузка в VictoriaMetrics (2 секунды)
```bash
curl -X POST http://localhost:8428/api/v1/import/prometheus \
     -T test_metrics_prometheus.txt
```

### Шаг 3: Запуск тестирования (7 секунд)
```bash
python3 test_forecast_system_v2.py
```
**Результат:** `forecast_test_results_validated.json`, консольный вывод

### Шаг 4: Анализ результатов
Используйте созданные отчеты для анализа:
- `FORECAST_RETEST_180_DAYS_SUMMARY.md` - быстрый обзор
- `FORECAST_RETEST_180_DAYS_RESULTS.md` - детальный анализ
- `FORECAST_FINAL_CONCLUSIONS_180_DAYS.md` - выводы
