# Математическое описание системы прогнозирования

Математическое описание системы базируется на представлении показателей функционирования станций сотовой связи в виде временных рядов. Для формализации процессов изменения метрик во времени используется аддитивная модель декомпозиции, реализованная в алгоритме Facebook Prophet. Данный подход позволяет представить исследуемый показатель как сумму нескольких независимых компонентов, каждый из которых отвечает за определенный аспект динамики данных.

Общее уравнение модели прогнозирования для произвольного показателя $y(t)$ в момент времени $t$ записывается следующим образом:

$$y(t) = g(t) + s(t) + h(t) + \varepsilon_t \qquad (1)$$

где каждая компонента описывается отдельной математической моделью.

## Моделирование тренда $g(t)$

Функция тренда $g(t)$ описывает непериодические изменения в значениях метрик, такие как постепенный рост трафика при увеличении числа абонентов или долгосрочное снижение качества сигнала. Prophet предоставляет два варианта моделирования тренда в зависимости от характера данных:

### Кусочно-линейный тренд

Кусочно-линейный тренд применяется для метрик с неограниченным ростом и определяется следующим образом:

$$g(t) = (k + \mathbf{a}(t)^T \boldsymbol{\delta}) \cdot t + (m + \mathbf{a}(t)^T \boldsymbol{\gamma}) \qquad (2)$$

где:
- $k$ — базовая скорость роста (наклон линии тренда);
- $\boldsymbol{\delta} = \{\delta_1, \delta_2, \ldots, \delta_S\}$ — вектор изменений скорости роста в точках излома $s_j$;
- $m$ — начальное смещение (intercept);
- $\mathbf{a}(t) = [a_1(t), a_2(t), \ldots, a_S(t)]^T$ — вектор индикаторных функций, где $a_j(t) = 1$, если $t \geq s_j$, иначе $0$;
- $\boldsymbol{\gamma} = \{\gamma_1, \gamma_2, \ldots, \gamma_S\}$ — вектор корректировок смещения, обеспечивающих непрерывность функции в точках излома, вычисляемый как $\gamma_j = (s_j - m) - \sum_{l<j} \gamma_l$.

Точки излома $s_j$ автоматически определяются алгоритмом либо задаются вручную. Данная модель используется для метрик сотовой сети, демонстрирующих изменение темпов роста, например, при расширении абонентской базы или модернизации оборудования.

### Логистический тренд

Логистический тренд применяется для метрик с естественным пределом роста (capacity) и описывается уравнением:

$$g(t) = \frac{C(t)}{1 + \exp(-(k + \mathbf{a}(t)^T \boldsymbol{\delta})(t - (m + \mathbf{a}(t)^T \boldsymbol{\gamma})))} \qquad (3)$$

где:
- $C(t)$ — функция емкости системы (максимальное достижимое значение);
- остальные параметры аналогичны кусочно-линейной модели.

Логистическая функция целесообразна для моделирования показателей с насыщением, таких как доля использования частотного ресурса (не может превышать 100%) или коэффициент использования каналов связи. Выбор между линейным и логистическим трендом осуществляется на основе анализа природы метрики: при наличии физических или технических ограничений на рост используется логистическая модель, в противном случае — кусочно-линейная.

## Моделирование сезонности $s(t)$

Сезонная составляющая $s(t)$ отвечает за периодические изменения, обусловленные суточной, еженедельной или годовой цикличностью использования услуг связи. В контексте сотовой сети это проявляется в виде предсказуемых пиков нагрузки в вечерние часы и спадов в ночное время.

Данный компонент моделируется с использованием рядов Фурье для аппроксимации произвольных гладких периодических функций:

$$s(t) = \sum_{n=1}^{N} \left( a_n \cdot \cos\left(\frac{2\pi nt}{P}\right) + b_n \cdot \sin\left(\frac{2\pi nt}{P}\right) \right) \qquad (4)$$

где:
- $P$ — период сезонности (например, $P = 7$ для недельной цикличности, $P = 365.25$ для годовой);
- $N$ — порядок ряда Фурье, определяющий количество гармоник для аппроксимации;
- $a_n$ и $b_n$ — коэффициенты Фурье, оцениваемые в процессе обучения модели методом наименьших квадратов.

Для повышения точности Prophet позволяет одновременно моделировать несколько типов сезонности. Например, для трафика сотовой сети могут быть определены:
- суточная сезонность ($P = 24$ часа, $N = 10$);
- недельная сезонность ($P = 7$ дней, $N = 3$);
- годовая сезонность ($P = 365.25$ дней, $N = 10$).

Увеличение параметра $N$ позволяет улавливать более сложные периодические паттерны, но повышает риск переобучения модели.

## Моделирование праздников и событий $h(t)$

Компонент $h(t)$ отражает влияние праздничных дней и специфических событий, которые приводят к аномальным отклонениям от стандартного профиля нагрузки. Математически это представляется в виде:

$$h(t) = \sum_{i=1}^{L} \kappa_i \cdot \mathbb{I}(t \in D_i) \qquad (5)$$

где:
- $L$ — количество учитываемых праздников и событий;
- $D_i$ — множество дат, соответствующих $i$-му празднику (может включать «окна» — дни до и после события);
- $\mathbb{I}(\cdot)$ — индикаторная функция, равная $1$, если условие истинно, и $0$ в противном случае;
- $\kappa_i$ — коэффициент влияния $i$-го события, оцениваемый из данных.

Например, для российских условий могут быть определены: новогодние праздники (резкий рост голосового трафика), День защитника Отечества, 8 Марта, майские праздники и др. Для каждого события модель автоматически оценивает степень его влияния на метрику.

## Стохастическая компонента $\varepsilon_t$

Ошибка $\varepsilon_t$ представляет собой случайную составляющую или «белый шум», который включает в себя любые изменения, не учтенные основными компонентами модели. В рамках Prophet предполагается, что $\varepsilon_t \sim \mathcal{N}(0, \sigma^2)$, то есть ошибки распределены нормально с нулевым математическим ожиданием и постоянной дисперсией $\sigma^2$. Параметр $\sigma^2$ оценивается на обучающей выборке и используется для построения доверительных интервалов прогноза.

## Оценка параметров модели

Все параметры модели ($k$, $m$, $\boldsymbol{\delta}$, $\boldsymbol{\gamma}$, $a_n$, $b_n$, $\kappa_i$, $\sigma^2$) оцениваются методом максимального правдоподобия с использованием L-BFGS алгоритма оптимизации. Для предотвращения переобучения применяется регуляризация параметров изменения тренда $\boldsymbol{\delta}$ и сезонных коэффициентов путем введения штрафа на их норму. Это обеспечивает устойчивость модели к выбросам и шуму в исторических данных.

Использование такой математической структуры позволяет программному комплексу не только эффективно восстанавливать пропущенные значения в телеметрии, но и строить устойчивые прогнозы с количественной оценкой неопределенности (доверительные интервалы), минимизируя влияние случайных выбросов данных. При этом интерпретируемость модели остается высокой: каждый компонент имеет ясный физический смысл и может быть проанализирован отдельно для понимания факторов, влияющих на поведение метрики.
