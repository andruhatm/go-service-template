# Исправление прав admin-service для Admin Panel

## Проблема
Клиент `admin-service` не имеет нужных ролей для вызова Keycloak Admin API, поэтому счетчики в админ панели показывают нули.

## Решение: Назначить роли через Keycloak UI

### Шаг 1: Откройте Keycloak Admin Console
1. Откройте http://localhost:8080
2. Войдите как admin/admin
3. Выберите realm **myrealm** (важно!)

### Шаг 2: Найдите service account клиента admin-service
1. В меню слева нажмите **Clients**
2. Найдите и кликните на **admin-service**
3. Перейдите на вкладку **Service account roles**

### Шаг 3: Назначьте роли realm-management
1. В разделе "Assign role" нажмите кнопку **Assign role**
2. В фильтре выберите **Filter by clients**
3. Найдите роли от клиента **realm-management**:
   - `view-realm`
   - `view-users`
   - `query-users`
   - `view-clients`
   - `view-events`
   - `query-clients`
   - `query-groups`
   - `query-realms`
   
4. Отметьте галочками все эти роли
5. Нажмите **Assign**

### Альтернатива (проще): Назначить роль realm-admin
Вместо множества отдельных ролей можно назначить одну роль `realm-admin`:
1. В "Filter by clients" найдите **realm-management**
2. Найдите роль `realm-admin`
3. Отметьте её галочкой
4. Нажмите **Assign**

### Шаг 4: Проверка
После назначения ролей:
1. Перезапустите backend (если он запущен)
2. Обновите страницу админ панели в браузере
3. Счетчики должны показать реальные данные вместо нулей

## Что это исправит
После этих действий:
- ✅ Бэкенд сможет получать токен для admin-service
- ✅ Токен будет иметь права на вызов Admin API
- ✅ Счетчики в админ панели покажут:
  - Количество пользователей
  - Количество сессий
  - Количество клиентов
  - Количество ролей
  - События входа и ошибки
