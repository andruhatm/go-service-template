## Таблица 2. Сравнение математических методов прогнозирования

| Характеристика метода | Разрабатываемая система | Аналог 1 (Cisco) | Аналог 2 (AT&T) | Аналог 3 (T-Mobile) |
|------------------------|-------------------------|------------------|-----------------|---------------------|
| **Тип модели** | Декомпозиционная (аддитивная) | Ансамбль ML-моделей | Классификационная ML | Статистическая |
| **Базовое уравнение** | $y = T + S + E$ | Ensemble($f_1, f_2, ..., f_k$) | $P(\text{anomaly}) = \sigma(\mathbf{w}^T \mathbf{x})$ | $\hat{y}_t = f(y_{t-1}, ..., y_{t-p})$ |
| **Трендовая компонента** | $T(t) = \beta_0 + \beta_1 t$ | Tree-based gradient boosting | Deep neural network | Simple moving average |
| **Сезонная компонента** | $S(h) = A \sin\left(\frac{2\pi(h-\phi)}{24}\right)$ | Feature engineering (hour, day) | Implicit in hidden layers | Not modeled |
| **Обработка шума** | Остаточная компонента $E(t) \sim \mathcal{N}(0, \sigma^2)$ | Ensemble variance reduction | Dropout regularization | Smoothing filter |
| **Оценка параметров** | OLS (Ordinary Least Squares) | Gradient descent | Backpropagation | Maximum likelihood |
| **Количество параметров** | 4-5 (β₀, β₁, A, φ) | 100-10,000 (зависит от модели) | 10,000-1,000,000 (нейросеть) | 10-30 (AR коэффициенты) |
| **Время обучения** | <1 минута (CPU) | 1-4 часа (GPU cluster) | 2-8 часов (GPU) | <5 минут (CPU) |
| **Время инференса** | <100 мс (1 метрика) | 500-2000 мс | 200-1000 мс | <200 мс |
| **Требования к памяти** | <10 МБ | 500 МБ - 2 ГБ | 1-4 ГБ | <50 МБ |
| **Устойчивость к выбросам** | Высокая (робастная регрессия) | Средняя (зависит от ансамбля) | Низкая (чувствительность к обучающим данным) | Низкая |
| **Обработка пропусков** | Интерполяция линейная | Imputation methods | Требует полных данных | Forward fill |
| **Переобучение** | Минимальное (мало параметров) | Риск средний (regularization) | Риск высокий (dropout, early stopping) | Риск низкий |

## Заключение

Проведенный патентный анализ выявил **6 ключевых отличительных признаков** разрабатываемой системы:

1. **Явная аддитивная декомпозиция** $y = T + S + E$ (отсутствует во всех аналогах)
2. **Гармонический анализ сезонности** с суточной периодичностью (отсутствует во всех аналогах)
3. **Rolling window validation** с ежечасным обновлением (отсутствует во всех аналогах)
4. **Длительная валидация** на 180-дневном наборе с 9 типами паттернов (отсутствует во всех аналогах)
5. **Открытая архитектура** на базе Prometheus/PostgreSQL/REST API (частично в аналогах, но не в таком сочетании)
6. **Специализация для телеком-метрик** с учетом доменной специфики

Совокупность этих признаков **не обнаружена ни в одном из 15 проанализированных российских и зарубежных патентов**, что свидетельствует о **новизне и патентоспособности** разработанного решения.

Достигнутая точность прогнозирования **WAPE = 3,90%** превышает типичные значения для телекоммуникационных систем (10-20%), что в сочетании с низкой вычислительной сложностью O(n) и высокой интерпретируемостью обеспечивает **изобретательский уровень**.
